# GlowEffectUpgrader

Minecraft-плагин для улучшения надетой брони и предметов в руках уникальными эффектами зелий через удобный графический интерфейс.

## Возможности
- GUI меню выбора снаряжения (/smith или /upgrade): шлем, нагрудник, поножи, ботинки, предмет в основной руке.
- Раздельная настройка эффектов, уровней, цен в Vault и PlayerPoints для каждого типа предметов.
- Покупка за валюту (ЛКМ) или поинты (ПКМ).
- Сохранение эффектов в PDC и отображение в Lore предмета.
- Автоматическое наложение и обновление эффектов во время ношения снаряжения.
- Команда /cleareffects для очистки эффектов с предмета.
- Полная кастомизация текстов через MiniMessage и конфигов без хардкода.

## Команды и права
- `/smith` (алиас `/upgrade`) — открыть меню улучшений (право: `eup.use`)
- `/smith reload` — перезагрузить конфиг и сообщения (право: `eup.admin`)
- `/cleareffects` — удалить эффекты с предмета в руке (право: `eup.clear`)
